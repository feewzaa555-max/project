## ภาพรวมโครงการ

โปรแกรมจองตั๋วภาพยนตร์ เขียนด้วย Java ล้วน ใช้แค่ไลบรารีมาตรฐาน หน้าจอทำด้วย Swing และเก็บข้อมูลทั้งหมดเป็นไฟล์ CSV

ผู้ใช้มี 2 แบบ

**ลูกค้า (USER)**
- สมัครบัญชีและเข้าสู่ระบบ ถ้ากรอกผิด ข้อความจะขึ้นใต้ช่องที่ผิด
- เลือกหนังและรอบฉายของวันนี้ (จองได้เฉพาะวันนี้ ไม่จองล่วงหน้า)
- เลือกที่นั่งได้หลายที่ในการจองครั้งเดียว ที่นั่งที่ถูกจองแล้วเป็นสีเทา กดไม่ได้
- เติมเงินเข้ากระเป๋าเงินในโปรแกรม แล้วใช้จ่ายค่าตั๋ว
- สมัครสมาชิกรายเดือนเพื่อรับส่วนลด
- ดูประวัติการจอง และได้ตั๋ว (E-Ticket) หลังจองสำเร็จ

**ผู้ดูแลระบบ (ADMIN)**
- เลือกหนัง 5 เรื่องที่จะฉายพรุ่งนี้ (Tomorrow's Lineup)
- เพิ่มหนังเรื่องใหม่ลง `movies.csv` พร้อมรูปโปสเตอร์ (+ Add New Movie)
- ตั้งเวลาของโปรแกรม (Program Clock) เพื่อสาธิตวันอื่น หรือกรณีรอบเริ่มฉายแล้ว โดยไม่ต้องรอเวลาจริง

## วิธีรันโปรแกรม

ต้องใช้ **Java 16 ขึ้นไป** (โค้ดใช้ `record`)

**VS Code**
1. เปิดโฟลเดอร์โปรเจกต์ (ที่มีโฟลเดอร์ `Booking_tickets` อยู่ข้างใน)
2. เปิดไฟล์ `Booking_tickets/src/gui/login/LoginFrame.java`
3. กด Run เหนือเมธอด `main`

**Command line** (รันในโฟลเดอร์ `Booking_tickets`)
```
javac -encoding UTF-8 -d out src/model/*.java src/exception/*.java src/repository/*.java src/service/*.java src/gui/login/*.java src/gui/main/*.java src/gui/admin/*.java
java -ea -cp out gui.login.LoginFrame
```
`-ea` เปิดการตรวจ `assert` (เมธอด `checkRep()` ของแต่ละคลาส) ช่วยจับข้อผิดพลาดภายในคลาสระหว่างพัฒนา

`AppServices` หาโฟลเดอร์ `data` ให้เอง รันจากโฟลเดอร์ที่อยู่เหนือ `Booking_tickets` หรือรันจากใน `Booking_tickets` ก็ได้

**บัญชีทดสอบ**

| ชื่อผู้ใช้ | รหัสผ่าน | บทบาท |
|---|---|---|
| `admin` | `admin1` | ADMIN (เข้าหน้า admin) |
| `testing` | `testing1` | USER (เข้าหน้าลูกค้า) |

## หนังและรอบฉาย

### หนัง (`movies.csv`)
รูปแบบ `รหัส,ชื่อเรื่อง,ความยาว(นาที),ที่อยู่โปสเตอร์` ตอนเริ่มมี 15 เรื่อง

| รหัส | ชื่อเรื่อง | นาที | รหัส | ชื่อเรื่อง | นาที |
|---|---|---|---|---|---|
| M1 | Spider-Man: Brand New Day | 145 | M9 | Inception | 148 |
| M2 | Pacific Rim | 131 | M10 | Interstellar | 169 |
| M3 | Ghost Rider | 110 | M11 | Oppenheimer | 180 |
| M4 | Jurassic Park III | 92 | M12 | Parasite | 132 |
| M5 | Blade Runner 2049 | 164 | M13 | Spirited Away | 125 |
| M6 | Hello World | 97 | M14 | The Dark Knight | 152 |
| M7 | Your Name | 106 | M15 | คู่แรด | 110 |
| M8 | Weathering with You | 112 | | | |

- หนังยาวได้ไม่เกิน 180 นาที (`Movie.MAX_DURATION_MINUTES`) รอบจะได้ไม่ทับกัน
- รูปโปสเตอร์อยู่ใน `data/posters/` ถ้าหาไฟล์รูปไม่เจอ หน้าลูกค้าจะโชว์การ์ดสีแทน

### ตารางรอบ (`schedule.csv`)
รูปแบบ `โรง,เวลาเริ่ม,เรื่องที่` มี 3 โรง โรงละ 5 รอบ ใช้ตารางเดียวกันทุกวัน
"เรื่องที่" หมายถึงลำดับใน lineup ของวันนั้น (ดูหัวข้อถัดไป) ไม่ใช่รหัสหนัง

| เวลา | โรง 1 | โรง 2 | โรง 3 |
|---|---|---|---|
| 08:45 | เรื่องที่ 1 | เรื่องที่ 3 | เรื่องที่ 5 |
| 11:45 | เรื่องที่ 2 | เรื่องที่ 4 | เรื่องที่ 1 |
| 14:45 | เรื่องที่ 3 | เรื่องที่ 5 | เรื่องที่ 2 |
| 17:45 | เรื่องที่ 4 | เรื่องที่ 1 | เรื่องที่ 3 |
| 20:45 | เรื่องที่ 5 | เรื่องที่ 2 | เรื่องที่ 4 |

### หนังที่ฉายแต่ละวัน (`lineup.csv`)
รูปแบบ `วันที่,รหัสหนังเรื่องที่1;2;3;4;5` เช่น `2026-10-01,M1;M2;M3;M4;M5`

- admin ตั้งได้เฉพาะของ **พรุ่งนี้** ของวันนี้ล็อกไว้ เพราะอาจมีคนจองตั๋วไปแล้ว
- ต้องเลือกให้ครบ 5 เรื่อง และห้ามซ้ำ
- วันไหนไม่ได้ตั้ง ใช้ชุดล่าสุดที่ตั้งไว้ก่อนหน้า หน้าลูกค้าจึงมีรอบทุกวัน

### กฎของรอบ
- จองได้เฉพาะรอบของวันนี้ ที่ยังไม่เริ่มฉาย รอบที่เริ่มแล้วปุ่มเป็นสีเทา กดไม่ได้
- หนังต้องจบก่อนเที่ยงคืน ถ้ารอบไหนจบเลยเที่ยงคืน โปรแกรมจะแจ้ง error ตอนอ่านไฟล์
- รหัสรอบเป็น `วันที่_Hโรง_เวลา` เช่น `2026-10-14_H3_1145` ใช้อ้างถึงรอบในไฟล์การจอง

## ราคา กระเป๋าเงิน และสมาชิก

### ราคาตั๋ว (`PriceCalculator`)

| ที่นั่ง | ทั่วไป | สมาชิก (ลด 10%) |
|---|---|---|
| Standard (A–E) | 160 บาท | 144 บาท |
| VIP (F, บวก 40 บาท) | 200 บาท | 180 บาท |

ตัวอย่าง: จอง A1 + F7 ราคาปกติ 360 บาท สมาชิกจ่าย 324 บาท

### กระเป๋าเงิน
- ผู้ใช้ใหม่มีเงิน 0 บาท
- เติมได้ครั้งละ 1–5,000 บาท (`Account.MIN_TOP_UP` / `MAX_TOP_UP`)
- จ่ายได้ไม่เกินเงินที่มี

### สมาชิกรายเดือน
- 99 บาท ต่อ 30 วัน (`AccountService.MEMBERSHIP_PRICE`, `Account.MEMBERSHIP_DAYS`) ตัดจากกระเป๋าเงิน
- ต่อก่อนหมดอายุ จะนับ 30 วันต่อจากวันหมดอายุเดิม วันที่เหลือไม่หาย
- หมดอายุแล้วค่อยสมัครใหม่ เริ่มนับ 30 วันจากตอนสมัคร
- ถ้าเงินไม่พอ กล่องจะถามว่าจะไปเติมเงินไหม
- สมัครจากหน้าเลือกที่นั่งได้ ราคาในการ์ดสรุปลดทันที

## กติกาการจอง (`BookingService`)

- จองได้เฉพาะรอบของวันนี้ที่ยังไม่เริ่ม
- เลือกอย่างน้อย 1 ที่ ห้ามเลือกที่ซ้ำ ห้ามเลือกที่ที่ถูกจองแล้ว
- กดยืนยันแล้วตัดเงินทันที เงินไม่พอจองไม่ได้
- **จองแล้วยกเลิกหรือคืนเงินไม่ได้** ไฟล์การจองจึงไม่มีช่องสถานะ แถวไหนอยู่ในไฟล์ = ที่นั่งนั้นถูกจองแล้ว
- รหัสการจองออกให้เรียงกันอัตโนมัติ B1, B2, B3, ...
- ประวัติการจองเรียงใหม่สุดไว้บน

ข้อความ error (ภาษาอังกฤษ) โชว์บนจอได้ทันที เช่น `Seat(s) already booked: A4`, `Insufficient balance: Current 300 THB, Required 400 THB`

## admin เพิ่มหนังใหม่ (`AdminService.addMovie`)

กด **+ Add New Movie** ในหน้า admin แล้วกรอกชื่อ ความยาว และเลือกรูป (ไม่เลือกรูปก็ได้)

| กฎ | ผิดแล้วขึ้น |
|---|---|
| ต้องเป็น admin | `Only admin can add movies.` |
| ชื่อห้ามว่าง | `Please enter a movie title.` |
| ความยาว 1–180 นาที | `Duration must be 1-180 minutes.` |
| รูปต้องเป็น .jpg / .jpeg / .png | `Poster must be a .jpg, .jpeg or .png file.` |
| ชื่อห้ามซ้ำ (ไม่สนตัวเล็กใหญ่) | `This movie already exists: M2` |
| ชื่อห้ามมี `,` (ไฟล์ CSV ใช้คั่นช่อง) | `Movie title and poster must not contain a comma (,)` |

ผ่านทุกข้อ:
1. ได้รหัสใหม่ = เลขมากสุด + 1 เช่น มีถึง M15 → `M16`
2. เพิ่มบรรทัด `M16,Dune: Part Two,166,posters/m16.jpg` ท้าย `movies.csv`
3. copy รูปไปเป็น `data/posters/m16.jpg` (ถ้ายังไม่มีโฟลเดอร์ posters จะสร้างให้)
4. ช่องเลือกหนังใน Tomorrow's Lineup มีเรื่องใหม่ให้เลือกทันที

## โครงสร้างโปรแกรม (`Booking_tickets/src/`)

แบ่งเป็นชั้นตามหน้าที่ ชั้นบนเรียกชั้นล่างผ่าน interface จึงเปลี่ยนวิธีเก็บข้อมูลได้โดยไม่ต้องแก้ส่วนที่เรียกใช้

| แพ็กเกจ | คลาส | หน้าที่ |
|---|---|---|
| `model` | `User`, `Role`, `Account`, `Movie`, `Showtime`, `Seat`, `SeatType`, `HallLayout`, `Booking` | ข้อมูลและกฎของข้อมูล แก้ค่าไม่ได้หลังสร้าง |
| `repository` | `UserRepository`, `AccountRepository`, `BookingRepository`, `MovieRepository` | interface บอกว่าอ่าน/บันทึกอะไรได้ |
| `repository` | `CsvUserRepository`, `CsvAccountRepository`, `CsvBookingRepository`, `CsvMovieRepository` | อ่าน/เขียนไฟล์ CSV จริง |
| `service` | `AuthService` | สมัครและเข้าสู่ระบบ |
| `service` | `MovieService` | หนังวันนี้ วันที่จองได้ รอบฉาย และรอบไหนยังจองได้ |
| `service` | `AccountService` | เติมเงิน จ่ายเงิน สมัคร/ต่อสมาชิก |
| `service` | `BookingService` | ตรวจกฎการจอง บันทึก ตัดเงิน ดูประวัติ |
| `service` | `PriceCalculator` | คิดราคา ที่เดียวที่รู้ราคาปกติและส่วนลด |
| `service` | `AdminService` | ตั้งหนังของพรุ่งนี้ และเพิ่มหนังใหม่ |
| `service` | `AppClock` | นาฬิกากลางของโปรแกรม ตั้งเวลาเองได้ และรีเซ็ตกลับเป็นเวลาจริงได้ |
| `service` | `AppServices` | สร้าง service ทุกตัวครั้งเดียวตอนเปิดโปรแกรม ทุกหน้าใช้ชุดเดียวกัน |
| `exception` | `AuthError`, `AuthField`, `AuthFormException` | error ของฟอร์ม Login / Sign up บอกได้ว่าขึ้นใต้ช่องไหน |
| `gui.login` | `LoginFrame`, `AuthCard`, `FormField`, `LoginTheme` | หน้า Login / Sign up (มี `main` ของโปรแกรม) |
| `gui.main` | `MainFrame`, `MainTopBar`, `DateBar`, `MovieRow`, `ShowtimeRow`, `MainTheme` | หน้าเลือกหนังของลูกค้า |
| `gui.main` | `SeatFrame`, `SeatMap`, `OrderSummary`, `TicketDialog` | หน้าเลือกที่นั่ง สรุปราคา และตั๋ว |
| `gui.main` | `TopUpDialog`, `MembershipDialog`, `HistoryDialog` | กล่องเติมเงิน สมัครสมาชิก ประวัติการจอง |
| `gui.admin` | `AdminFrame`, `AdminTopBar`, `LineupPanel`, `ClockPanel`, `AddMovieDialog`, `MovieRenderer`, `AdminTheme` | หน้า admin |

หน้าจอแต่ละหน้าแยกเป็นชิ้นเล็กตามหน้าที่ แต่ละชิ้นบอกหน้าหลักผ่าน `Runnable` (เช่น กดที่นั่ง → `SeatMap` เรียก `onChange.run()` → `SeatFrame` คิดราคาใหม่) และแต่ละหน้ามีไฟล์ Theme ของตัวเองเก็บสีและฟอนต์ไว้ที่เดียว

## หลักการออกแบบ (Software Construction)

- **ข้อมูลแก้ไม่ได้ (immutable):** ข้อมูลส่วนใหญ่เป็น `record` เมธอดที่ทำให้ค่าเปลี่ยน เช่น `Account.topUp` จะคืน object ตัวใหม่
- **ตรวจค่าตั้งแต่ต้นทาง (fail-fast):** ตรวจค่าใน constructor ข้อมูลผิดจากไฟล์ CSV จะถูกจับทันทีที่อ่าน ไม่ลามไปพังที่อื่น
- **สัญญาของคลาส:** ทุกคลาสมีคอมเมนต์ Abstraction Function, Rep Invariant, Safety from rep exposure และเมธอด `checkRep()` ที่ตรวจด้วย `assert` (รันด้วย `-ea`)
- **Javadoc ครบทุกเมธอด:** ทุกเมธอดมี `@param` / `@return` / `@throws` พร้อมตัวอย่างค่าจริง
- **แยกหน้าที่:** model เก็บข้อมูล, repository จัดการไฟล์, service ทำงานตามกฎ, gui แสดงผลอย่างเดียว
- **พึ่ง interface ไม่พึ่งคลาสจริง (DIP):** service รับ repository ผ่าน constructor เปลี่ยนที่เก็บข้อมูลหรือทดสอบด้วยตัวปลอมได้
- **ไม่มีตัวเลขลอย:** ราคา ส่วนลด ขนาดผัง จำนวนวันสมาชิก ความยาวหนังสูงสุด เป็นค่าคงที่มีชื่อ อยู่ที่เดียว
- **นาฬิกาตัวเดียวทั้งโปรแกรม:** ไม่มีที่ไหนเรียกเวลาเครื่องตรง ๆ สาธิตด้วยการตั้งเวลาได้ และผลทดสอบไม่เปลี่ยนตามเวลาที่รัน
